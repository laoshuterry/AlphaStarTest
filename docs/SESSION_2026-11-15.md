## 已跑通的手动双端命令

先在两个终端分别进入项目目录。真人端看到 `Join:` 后，再启动 Agent。

真人端：

```bash
cd /Volumes/MacExt/Developer/sc2-coach
export SC2PATH="/Volumes/MacExt/BattleNet/StarCraft II"
mkdir -p logs
./.venv-pysc2/bin/python -u -m pysc2.bin.play_vs_agent \
  --human --map Simple64 --host 127.0.0.1 --config_port 14380 \
  --realtime --render --rgb_screen_size 0 --rgb_minimap_size 0 \
  2>&1 | tee "logs/lan-human-$(date +%Y%m%d-%H%M%S).log"
```

Agent 端：

```bash
cd /Volumes/MacExt/Developer/sc2-coach
export SC2PATH="/Volumes/MacExt/BattleNet/StarCraft II"
mkdir -p logs
./.venv-pysc2/bin/python -u -m pysc2.bin.play_vs_agent \
  --host 127.0.0.1 --config_port 14380 --realtime --norender \
  --agent pysc2.agents.random_agent.RandomAgent \
  --rgb_screen_size 0 --rgb_minimap_size 0 \
  2>&1 | tee "logs/lan-agent-$(date +%Y%m%d-%H%M%S).log"
```

在 PySC2/Pygame 窗口左键选单位，右键移动或采矿，点击小地图移动视角，`/` 查看帮助。
`--norender` 不开启该输入窗口，之前两端均使用它时用户无法操作。
手动启动的进程在各自终端按 Ctrl+C 停止；不由 lan.py 管理。

## 后台启动脚本

```bash
cd /Volumes/MacExt/Developer/sc2-coach
python3 lan.py start
python3 lan.py status
python3 lan.py stop
python3 lan.py status
```

`start` 先等真人端就绪，再启动 Agent，确认加入后启动器返回；双端继续后台运行，
但真人操作窗口仍可见。日志在 `logs/lan-时间/human.log` 和 `agent.log`。
进程信息在 `logs/.lan-run/state.json`。不是系统服务，不会重启机器后自启动或自动重启崩溃的客户端。
不要在进程仍运行时删除日志或状态文件；修正版停止功能依赖它们找回残留 SC2。
修正版以启动时间校验 PID，跟踪子进程，并根据日志中本次 SC2 的唯一 tempDir 找回孤立进程；
失败会报错，不再无条件报告停止。真实停止仍需验证，不要把模拟测试当成成功实测。
